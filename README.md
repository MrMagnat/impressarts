# Складской дашборд (управление запасами · данные из 1С)

Веб-панель управления складскими запасами: **Дашборд · Каталог · Отчёты · Настройки**.
Стек: TypeScript — Fastify + `node:sqlite` (backend/API), React + Vite + Tailwind + Recharts (frontend).

## Что внутри
- **Каталог** — дерево `Тип → Вид → Группа → Позиция → Партии`, drill-down, поиск, «заморожено в деньгах» на каждом уровне. Карточка позиции: партии (серия, изготовлено, годен до, остаток дней, менеджер, заказчик), менеджеры/заказчики, история за 78 недель, конкурентный отчёт.
- **Дашборд** — KPI (заморожено ₽, тоннаж, позиции, партии), динамика, структура по типам, топ категорий, сроки годности, топ менеджеров/заказчиков. Переключатель ₽/кг.
- **Отчёты** — недельные и месячные, сравнение с предыдущим и средним периодом, раскрытие по категориям, топ-движения, экспорт в **PDF**.
- **Настройки** — цены ₽/кг по видам (пересчёт сумм), импорт Excel-выгрузки из 1С, общие параметры и пароль.

Данные: реальная выгрузка `data/seed/demo.xlsx` (снимок на 14.08.2026, 41 838 партий, 3 036 позиций). История по неделям **смоделирована** назад на основе трендов/сезонности. Цены **модельные** (₽/кг по видам) — заменяются на прайс из 1С позже.

## Запуск (локально)
```bash
npm install
npm --workspace server install
npm --workspace web install
npm run etl          # собрать БД из data/seed/demo.xlsx + смоделировать историю
npm run build        # собрать фронтенд
npm start            # сервер на http://localhost:3000 (отдаёт и API, и UI)
```
Режим разработки (два порта, hot-reload):
```bash
npm run dev          # server :3021 + web :5199
```

**Пароль по умолчанию:** `demo` (меняется в Настройках или через `AUTH_PASSWORD`).

## Переменные окружения
- `PORT` (по умолчанию 3000), `HOST` (0.0.0.0)
- `AUTH_PASSWORD` — пароль входа
- `COOKIE_SECRET` — секрет подписи cookie (задать в проде)
- `DB_PATH` — путь к файлу БД (по умолчанию `data/sklad.db`)

## Обновление данных
Загрузить свежую выгрузку из 1С: **Настройки → Импорт**, либо положить `.xlsx` и вызвать `npm run etl <путь>`.
Для «проверять каждый день» — cron на сервере, кладущий выгрузку и вызывающий импорт.
