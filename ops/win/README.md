# Вход на сервер с Windows одним кликом

Два файла для рабочего компьютера (не для сервера). Оба на латинице — их можно
копировать через «Блокнот» в любой кодировке, ничего не сломается.

## Разовая настройка

Запустить **`impress-setup.cmd`** двойным кликом. Он спросит IP и логин, дальше:

1. создаст SSH-ключ `%USERPROFILE%\.ssh\id_ed25519_impress`;
2. положит его на сервер — **пароль спросят один раз**, его вводит сам `ssh`;
3. пропишет короткое имя `impress` в `%USERPROFILE%\.ssh\config`;
4. создаст на рабочем столе ярлык **Impress server**;
5. проверит, что вход по ключу работает.

Пароль нигде не сохраняется: скрипт его не видит и не записывает. Дальше он вообще
не нужен — сервер узнаёт компьютер по ключу.

## Повседневная работа

Двойной клик по **Impress server** на рабочем столе — открывается консоль сервера
сразу в `/opt/impressarts-main`. Из командной строки то же самое:

```
ssh impress
```

## Если что-то поменялось

- **Сменился IP сервера** — поправьте строку `HostName` в `%USERPROFILE%\.ssh\config`.
- **Другой каталог проекта** — поправьте путь в `Impress server.cmd` на рабочем столе.
- **Нужен ещё один компьютер** — запустите `impress-setup.cmd` и на нём: у каждой машины
  свой ключ, друг другу они не мешают.
- **Убрать доступ с потерянного компьютера** — удалить его строку из
  `~/.ssh/authorized_keys` на сервере.

## Требования

Клиент OpenSSH — в Windows 10/11 он есть из коробки. Если `ssh` не находится:
Параметры → Приложения → Дополнительные компоненты → Добавить компонент → «Клиент OpenSSH».

## Безопасность

После настройки имеет смысл выключить на сервере вход по паролю — тогда подобрать его
будет невозможно. В `/etc/ssh/sshd_config`:

```
PasswordAuthentication no
```

и `sudo systemctl restart ssh`. Делайте это **только убедившись, что вход по ключу
работает**, и не закрывая текущую сессию — иначе можно запереть себя снаружи.
